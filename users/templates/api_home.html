Spam Detection REST API

Status: Running

This is an API-only backend. You can use Postman or any HTTP client to test the endpoints.

Endpoints

  • POST /register/ – Register a new user
  • POST /login/ – Obtain JWT token
  • GET /contacts/ – List your contacts (protected)
  • POST /mark-spam/ – Mark a phone number as spam (protected)
  • GET /search-by-name/?name=<name> – Search contacts by name (protected)
  • GET /search-by-phone/?phone_number=<number> – Search by phone number (protected)

For full documentation and examples, visit the GitHub README.
